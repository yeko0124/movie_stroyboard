# 스토리보드

영상과 이미지를 캔버스에 올려 씬을 짜고, 같이 코멘트하는 도구. 3인 정도의 팀용으로 만들었다.

- 프레임을 캔버스 아무 데나 놓는다. 놓인 위치대로 번호와 연결선이 알아서 따라온다
- 파일을 끌어다 놓으면 들어간다. 여러 개를 한 번에 놓으면 순서대로 채워진다
- 드래그로 여러 개를 골라 **선택한 것만 이어서 재생**할 수 있다 (애니매틱 미리보기)
- 프레임마다 코멘트를 달고, 누가 썼는지 프로필 사진으로 본다
- 밝은 화면 / 어두운 화면 전환

## 실행

`run.bat` 을 더블클릭한다. 처음 한 번은 준비하느라 1~2분 걸리고, 그다음부터는 바로 뜬다.

창에 주소가 두 개 찍힌다.

```
내 PC        http://localhost:8080
같은 네트워크 http://192.168.0.12:8080     ← 팀원에게 알려줄 주소
```

**이 창을 닫으면 서버도 꺼진다.** 팀원이 쓰는 동안은 켜 둔다.

Python이 없다는 메시지가 나오면 [python.org](https://www.python.org/downloads/)에서 설치하고,
설치 화면의 **"Add python.exe to PATH"** 를 반드시 체크한다.

### 팀원이 접속이 안 될 때

같은 공유기(사무실 와이파이 등)에 붙어 있어야 한다. 그런데도 안 되면 방화벽이 막고 있는 것이다.
Windows 방화벽에서 8080 포트를 열거나, 처음 실행할 때 뜨는 "액세스 허용" 창에서 허용을 누른다.

## 밖에서도 접속하기

`run.bat` 으로 띄운 주소(`192.168.x.x`)는 **같은 공유기 안에서만** 닿는다. 밖에서도 쓰려면 두 가지 방법이 있다. 둘 다 무료다.

어느 쪽이든 **이 PC는 켜져 있어야 한다.** 이 PC가 서버라서 그렇다.
꺼져 있는 동안은 접속만 안 될 뿐, 데이터는 `data/` 와 `media/` 에 그대로 남는다.

### 방법 1 — Cloudflare 터널 (팀원은 설치할 게 없다)

`run-share.bat` 을 실행한다. 알아서 이렇게 한다.

1. 초대 코드가 없으면 하나 만들어 `.env` 에 적어 둔다 (밖으로 열리니 잠가야 한다)
2. `cloudflared` 를 받아 `bin/` 에 둔다 (약 18MB, 처음 한 번만)
3. 서버와 터널을 켜고 주소를 찍어 준다

```
┌─────────────────────────────────────────────────────
│  팀원에게 이 주소와 코드를 알려주세요
│
│    주소   https://locks-dairy-referrals-originally.trycloudflare.com
│    코드   flint-2432
└─────────────────────────────────────────────────────
```

팀원은 이 주소로 들어와 코드를 넣으면 된다. 휴대폰에서도 된다.

- **껐다 켜면 주소가 바뀐다.** 그때마다 새 주소를 알려줘야 한다. (무료 Cloudflare 계정과 도메인이 있으면 고정할 수 있다)
- 초대 코드는 `.env` 에 남으므로 그다음부터는 같은 코드를 쓴다. `run.bat` 으로 띄울 때도 코드를 묻게 되니, 사내에서 코드 없이 쓰고 싶으면 `.env` 의 `INVITE_CODE` 줄 앞에 `#` 을 붙인다.
- 확인해 본 것: 영상 구간 탐색(중간으로 건너뛰기)이 터널 너머에서도 정상 동작하고, 120MB 파일 업로드도 통과했다. 다만 인터넷을 타므로 큰 파일은 사내망보다 느리다.

### 방법 2 — Tailscale (외부에 아예 노출하지 않는다)

셋이서만 연결되는 사설망을 만드는 방식이라 인터넷에 열리지 않는다. 대신 **각자 설치**해야 한다.

1. 세 명 모두 [tailscale.com/download](https://tailscale.com/download) 에서 설치하고 같은 계정으로 로그인한다
   (개인 무료 플랜이 3명까지 커버한다. 회사 PC에 설치하려면 관리자 권한이 필요할 수 있다)
2. 이 PC에서 `run.bat` 을 실행한다
3. 팀원은 `http://<이 PC의 Tailscale 이름>:8080` 으로 접속한다
   (이름은 Tailscale 관리 화면이나 트레이 메뉴에서 확인한다. `http://100.x.x.x:8080` 형태의 IP 도 된다)

주소가 바뀌지 않는 게 장점이다. 이 경우 초대 코드는 없어도 되지만, 켜 두면 더 안전하다.

## 집으로 옮기기

이 폴더 하나에 전부 들어 있다. **폴더째 복사해서 옮기고 `run.bat` 을 실행하면 그대로 이어서 쓴다.**

| 폴더 | 내용 |
|---|---|
| `data/` | 보드, 프레임, 코멘트, 계정 (`storyboard.db` 파일 하나) |
| `media/` | 올린 영상과 이미지 |
| `.env` | 초대 코드 등 설정 |
| `.venv/`, `bin/` | 파이썬 꾸러미와 cloudflared. 안 옮겨도 된다 (없으면 다시 만든다) |

USB로 옮길 때 `.venv` 와 `bin` 은 빼고 `data`, `media`, 나머지 파일만 복사하면 용량이 줄어든다.

## 조작

| 하고 싶은 것 | 방법 |
|---|---|
| 확대 / 축소 | **마우스 휠**을 굴린다. 트랙패드는 **두 손가락으로 오므리기/벌리기**. 터치 화면도 같다 |
| 화면 이동 | **스페이스 + 끌기**, 마우스 가운데 버튼 끌기, 또는 트랙패드 두 손가락 스크롤 |
| 전체 보기 | 아래 가운데 **전체 보기** |
| 프레임 옮기기 | 프레임을 잡고 끈다 (여러 개 선택했으면 같이 움직인다) |
| 여러 개 선택 | 빈 곳에서 드래그해 훑는다. `Shift` + 클릭으로 추가/해제, `Ctrl+A` 전체 선택 |
| 선택한 것만 이어 보기 | 선택하면 오른쪽에 뜨는 **▶ 이어서 재생** (또는 `Enter`) |
| 파일 넣기 | 프레임 위로 끌어다 놓기. 프레임을 더블클릭해서 골라도 된다 |
| 빈 곳에 새로 만들기 | 캔버스 빈 곳에 파일을 떨어뜨리면 그 자리에 프레임이 생긴다 |
| 크게 보기 / 코멘트 | 프레임 가운데 ▶ 버튼, 또는 더블클릭 |
| 프레임 지우기 | 선택하고 `Delete` |

이어서 재생 중에는 `Space` 재생/멈춤, `←` `→` 앞뒤 이동, `Esc` 닫기.
영상은 끝까지 재생하고 다음으로 넘어가고, 이미지는 3초씩 보여 준다.

### 휠이 원하는 대로 안 움직일 때

기본값은 **자동**이다. 마우스 휠이면 확대하고, 트랙패드 두 손가락 스크롤이면 화면을 옮긴다.
쓰는 장비에 따라 이 구분이 어긋날 수 있어서, 아래 가운데 HUD 의 **`휠 자동`** 버튼을 누르면 바꿀 수 있다.

| 표시 | 휠을 굴리면 |
|---|---|
| `휠 자동` | 마우스면 확대, 트랙패드면 이동 (기본값) |
| `휠 확대` | 언제나 확대 |
| `휠 이동` | 언제나 화면 이동 (`Ctrl`+휠이 확대) |

한 번 고르면 그 브라우저에 기억된다. 어느 설정이든 `Ctrl`+휠과 트랙패드 오므리기는 항상 확대다.

## 설정 — `.env`

`.env.example` 을 복사해서 이름을 `.env` 로 바꾸고 필요한 줄만 고친다. 서버를 다시 켜면 적용된다.

```ini
# 초대 코드. 비워 두면 코드 없이 누구나 들어온다 (지금 설정)
# INVITE_CODE=cut-01

PORT=8080
MAX_UPLOAD_MB=2048
```

초대 코드를 넣으면 접속할 때 코드를 먼저 묻는다. 코드를 통과하면 이름과 프로필 사진을 고르고 들어온다.
한 번 만든 프로필은 다음부터 목록에서 고르면 된다.

## 영상 저장 위치 옮기기 (디스크가 부담될 때)

기본은 이 폴더의 `media/` 다. 로컬 용량이 아까우면 Cloudflare R2 로 옮길 수 있다.
무료로 10GB 를 주고, 다운로드 트래픽 요금이 없어서 영상에 적합하다.

1. `pip install boto3` (또는 `.venv\Scripts\python.exe -m pip install boto3`)
2. R2 에서 버킷과 API 토큰을 만든다
3. `.env` 에 아래를 채운다

```ini
STORAGE_BACKEND=r2
R2_ACCOUNT_ID=...
R2_BUCKET=storyboard
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
```

> R2 백엔드 코드는 들어 있지만 실제 R2 계정으로 돌려 보지는 않았다. 전환할 때 파일 하나 올려서 확인해 보는 게 좋다.
> 이미 `media/` 에 있는 파일은 자동으로 옮겨 가지 않는다. 옮기려면 버킷에 같은 경로(`scenes/…`, `avatars/…`)로 복사해 넣으면 된다.

**GitHub 는 영상 보관에 맞지 않는다.** 저장소는 파일당 100MB 가 한계고, Git LFS 는 무료 1GB 뿐이다.

## 만듦새

- 서버: Python + FastAPI, 데이터는 SQLite 파일 하나
- 화면: 별도 빌드 없는 정적 HTML/CSS/JS
- 영상은 Range 요청을 지원해서 중간으로 건너뛰어도 바로 재생된다
- 다른 사람이 바꾼 내용은 5초마다 알아서 따라온다

암호 없이 초대 코드만으로 들어오는 구조라 **사내망이나 아는 사람끼리 쓰는 용도**다.
인터넷에 그대로 열어 두는 것은 권하지 않는다.

### 파일 구성

```
run.bat        서버만 켠다 (같은 와이파이)
run-share.bat  서버 + 터널 (밖에서도 접속)
main.py        API 와 화면 서빙
share.py       터널 준비와 실행
config.py      설정 (.env 읽기)
db.py          SQLite 스키마
storage.py     파일 저장 (로컬 / R2 교체 가능)
static/        화면 (index.html, style.css, app.js)
```
